# Prewatchr
 
Browser extension for Chrome and Firefox that shows an AI-generated summary of any YouTube video before you open it.
 
**[▶ Check it → jucofuco.github.io/projects/prewatchr](https://jucofuco.github.io/projects/prewatchr)**

Press `Ctrl+Shift+X`, click a thumbnail, and get a summary in seconds — without watching the video.
 
**Install:** [Chrome](https://chromewebstore.google.com/detail/prewatchr-for-youtube/bphadcjnnckfoiaglnidkjhlbnbheala) · [Firefox](https://addons.mozilla.org/en-GB/firefox/addon/prewatchr-for-youtube/)
